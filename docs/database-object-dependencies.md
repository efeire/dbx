# 查看 Oracle 例程依赖

在 Oracle 或 OceanBase Oracle 连接的对象树中，右键单独的过程、函数、程序包或程序包成员，选择「查看依赖关系」。DBX 会在现有查询标签页运行只读查询。

结果只包含当前连接账户可见的直接目录记录，分为 `DEPENDS_ON`（目标依赖的对象）和 `REFERENCED_BY`（直接引用目标的对象）。结果保留字典中的 owner、名称、对象类型、依赖类型和数据库链接名；不会递归展开依赖链，也不会自动解析同义词或远端数据库链接。

程序包成员会按所属程序包查询，标签页标题会标明程序包范围。依赖目录记录的是程序包/程序包主体，不足以归属到单个成员，因此结果不代表成员级依赖。

动态 SQL 中的对象引用可能不会出现在依赖目录中。无权限访问的记录不会由 DBX 提权补查；目录查询错误会直接显示为查询失败。
